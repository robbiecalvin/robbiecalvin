# Landing page design

Every active landing page uses its own optimized WebP hero background, selected with page-specific `--hero-image` rules in `pages.css`. The original Codex Master artwork is retained; 16 additional images were generated for the other overview and personal pages. The homepage keeps its existing Vancouver `hero-bg.png`.

`assets/styles/pages.css` contains the individual page compositions. `assets/styles/overview.css` supplies typography, navigation, shared controls, and homepage-matched palette tokens. `assets/scripts/pages.js` handles pricing estimates, QuickWoo's explanatory mode switch, and FobFather's copy bundle selector. `overview.js` continues to handle brief downloads.
