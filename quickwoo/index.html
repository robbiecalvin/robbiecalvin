01 / The experience

Your sites and stores. One desktop workspace.

QuickWoo Desktop brings WordPress and WooCommerce operations into one desktop app. Switch between Site Mode and Store Mode, move between connected sites, and shape a dashboard around the work you need to do.

01 /

See the store clearly

Store Mode brings orders, products, customer insights, snapshots, and notifications into a configurable dashboard.

02 /

Keep the site in view

Site Mode gathers pages, posts, site health, content information, and management tools in the same application shell.

03 /

Make the workspace yours

Reorder, collapse, and hide dashboard sections, save views, and use Quick Find to jump to content, orders, and actions.

02 / How it fits together

A desktop hub connected to your site.

WooCommerce credentials connect the store. WordPress access and the bundled Quick Connector enable the server-side actions that need them. Site selection and per-site layouts help keep different projects organized.

03 / Explore the project

Check the connection requirements

The README documents desktop setup and the required connector for WordPress-side module actions. The current testing tier allows five sites; that is an implementation limit, not an announced paid plan. Auxil and Opera remain coming-soon placeholders.
