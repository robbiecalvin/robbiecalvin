01 / The experience

Your sites and stores. One desktop workspace.

QuickWoo Desktop brings WordPress and WooCommerce operations into one desktop app. Switch between Site Mode and Store Mode, move between connected sites, and shape a dashboard around the work you need to do.

01 /

See the store clearly

Store Mode brings orders, products, customer insights, snapshots, and notifications into a configurable dashboard.

02 /

Keep the site in view

Site Mode gathers pages, posts, site health, content information, and management tools in the same application shell.

03 /

Make the workspace yours

Reorder, collapse, and hide dashboard sections, save views, and use Quick Find to jump to content, orders, and actions.

02 / How it fits together

A desktop hub connected to your site.

WooCommerce credentials connect the store. WordPress access and the bundled Quick Connector enable the server-side actions that need them. Site selection and per-site layouts help keep different projects organized.

Run it on your computer

Start with the GitHub project.

1. Check Releases first

Open the repository’s Releases page. If an installer is published for your operating system, read its release notes and download that installer. Availability depends on what has been released.

View GitHub releases ↗

2. Or run the source

The documented project currently provides a development workflow. You’ll need Git and a supported Node.js version (22.12+ or 24). A source ZIP is project code, not an installer.

git clone https://github.com/robbiecalvin/QuickWoo-Desktop.git
cd QuickWoo-Desktop
npm install
npm run dev

3. Connect your own site

Use your WooCommerce REST credentials. WordPress-side actions need WordPress access and the bundled Quick Connector installed on your site. Follow the repository’s current setup and compatibility instructions.

Only use sites you are authorized to manage. Downloading the project does not include hosting or a managed setup service.
