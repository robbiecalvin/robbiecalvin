Ruby on Rails job board

Launchboard

A Ruby on Rails portfolio project that uses a job board to demonstrate how routes, controllers, database models, and views fit together.

View source on GitHub ↗

How it works

Public job listings

Visitors can filter listings by company, location, and remote availability, then open a posting and submit an application. Seed data makes that workflow easy to review locally.

Admin workflow

The admin area manages companies and their job listings. Active Record connects each listing to its company and the applications it receives.

Request-level verification

The request tests exercise the application through HTTP routes. The source repository contains the test suite and local setup instructions.

Inside the Rails job board

Launchboard is a portfolio application that shows a job board built with conventional Rails patterns.

RESTful routes connect the interface to Rails controllers, Active Record associations model the records, and request tests check the application flows. Seed data supports local exploration.
