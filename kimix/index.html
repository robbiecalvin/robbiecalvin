01 / The experience

Listen. Layer. Make it yours.

KIMIX brings music playback and multitrack editing into one audio workspace. Switch between a visual Now Playing screen, a queue-style Playlist, and an Editor for arranging clips and building a mix.

01 /

Set the listening session

Add local tracks or scan a folder, filter favorites, resume a listening session, and choose optional crossfade transitions in the desktop app.

02 /

Build on the timeline

Split, copy, paste, and move clips across tracks. Use per-track and per-clip volume, undo and redo, and microphone recording in the desktop editor.

03 /

Bring the mix together

Layer audio and export from the desktop app with progress and cancellation. A browser implementation also supports local audio import, timeline editing, and local mix playback.

02 / How it fits together

Two ways into the same idea.

The Python desktop app offers the fuller editing and export workflow. The browser build shares the three-mode shell and multi-row timeline, including a dedicated Final Product row.

03 / Explore the project

Choose your workspace

The repository includes desktop setup, standalone build scripts, and browser setup. Desktop setup recommends Python 3.11 or 3.12 and FFmpeg; browser capabilities differ from the desktop feature set.
