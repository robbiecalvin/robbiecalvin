Before choosing a plan

A few useful distinctions.

Are only Lite editions free?

The temporary free promotion covers all listed WordPress plugin modules. Review each release package’s included license, features, and requirements.

Will I be charged monthly or annually?

No payment is required for the WordPress plugins while this promotion is active. A download does not start a paid subscription.

Is QuickWoo Desktop free too?

The WordPress plugins are temporarily free. The separate Desktop application and its commercial plan are not included in this promotion.

How do I get a free plugin?

Open the plugin page. Published ZIP packages have a download button; where a release ZIP is still being prepared, use the free-package request link. No plugin payment is required.

What is in the Education Bundle?

Education contains Quick Course Builder. The plugin and the Education collection are both included in the temporary free promotion.

When does the free promotion end?

No end date has been announced. This promotion does not promise a lifetime paid subscription, hosting, or a managed service.
