Quick Add / Guide

How to bulk add WooCommerce products from JSON

Quick Add creates new WooCommerce products from a JSON array pasted into WordPress. This example creates a tote and a notebook in one batch, with a unique SKU and stock quantity for each.

Start with a two-product JSON example

Use one object per product. Include product_name and regular_price in each object. The example also supplies optional sku and stock_quantity values. Replace the demo SKUs with unique values before reusing the example on the same store.

[
  {
    "product_name": "Demo Canvas Tote",
    "regular_price": "18.00",
    "sku": "DEMO-TOTE-001",
    "stock_quantity": 12
  },
  {
    "product_name": "Demo Notebook",
    "regular_price": "9.50",
    "sku": "DEMO-NOTE-001",
    "stock_quantity": 20
  }
]

Download the example JSON

Paste and preview the batch in WordPress

  1. Activate WooCommerce and Quick Add on a staging store. This walkthrough was tested with Quick Add 1.0.2. Sign in with an account that can manage WooCommerce.
  2. In Quick Add → Settings, set Default Product Status to Draft so you can review the new products before publishing.
  3. Open Quick Add → Bulk Add, choose JSON Paste Mode, and paste the array into Paste JSON Array of Products.
  4. Click Validate & Preview JSON. Check the preview for the expected names, prices, and SKUs. The preview checks JSON syntax and required fields. WooCommerce catalogue checks run when you submit.
  5. Click Create Products. Review the success count and any row errors, then open Products to confirm the drafts, prices, SKUs, and stock quantities.

Check the products in WooCommerce

In the test store, both rows appeared under Products → Drafts. The notebook showed a price of 9.50 and a stock count of 20. The tote showed 18.00 and a stock count of 12.

If some rows fail

  • Invalid JSON usually means a syntax issue. Check for the outer square brackets, double quotes, and trailing commas.
  • Duplicate SKU means a SKU repeats in the batch or already exists in the catalogue. Use a unique SKU for each new product.
  • Some products were created means you should review the results and retry only the unsuccessful rows. Quick Add creates new products, so resubmitting successful rows without SKUs can create duplicates.
