From brief to reviewable plan

Describe the site

Start with a website type, market, language, and objective. The sample project uses a SaaS brief focused on qualified organic leads.

Order the work

The Python planner selects applicable skills and resolves dependencies. The example dashboard shows 68 planned skills. Planning leaves those skills for review and execution as separate steps.

Review the evidence

Use supplied data for offline analysis. The local workspace keeps project records and analysis history in SQLite and can export a record for review.

Where AI fits

The repository includes explicit instructions for manual Codex workflows. The Python planner handles selection and ordering, while evidence and recommendations go through human review.
