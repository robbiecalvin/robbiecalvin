AI Software Workshop

Work through a small task manager example, from the first brief to a tested revision. You can explore the lessons here, then try the exercises with the coding assistant of your choice.

Start the first lesson See the work behind it

Write a brief you can test

Specify the outcome, constraints, and evidence before asking for code. Use a concrete test so you know when the first version is ready.

Open the example prompt

Build a small browser task list with a title field and a Complete action. Keep tasks in this browser, with no login or server. Reject titles containing only spaces. Show me how to test adding a task, completing it, and refreshing the page.

Try it: Write a four-sentence brief for a notes app. Include how notes are saved and one input the app should reject.

Check: Could someone else use your brief to tell whether the result meets both requirements?

Check the output yourself

Turn the brief into observable steps. Record what you saw, including anything you could only infer from the code.

Open the worked test list
  1. Submit a title containing only spaces. Confirm the list stays unchanged.
  2. Add a valid task, mark it complete, and reload. Confirm the entry and completion state persist.
  3. Repeat the main flow with the keyboard. Check that you can locate and operate the controls.

Try it: Run the steps on the task manager demo. Record the expected and observed result for each step.

Revise using a specific observation

Give the assistant the smallest failing case you found, the expected result, and the behaviours it should preserve. Run the original checks again after the change.

Open a sample revision request

When I submit three spaces, the task list adds an empty item. The expected result is no new item. Reject whitespace-only titles while preserving task completion and saving on reload. After the fix, repeat the original three checks.

Try it: Write a revision request from one of your observations. If your checks passed, add one new testable requirement and describe how to verify it.
