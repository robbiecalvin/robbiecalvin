SEO Auditor

A Python command-line tool that crawls a website and puts common on-page SEO findings into CSV and HTML reports.

View source on GitHub ↗

How it works

Crawl a site

Seed the audit with a URL. The crawler follows internal links and records HTTP status and response timing for the pages it reaches.

Review metadata and links

The checks flag title and description length, repeated metadata, missing image alt text, and broken links. These findings give reviewers a list of issues to investigate.

Export findings

Open the HTML report to review the results or use CSV for spreadsheet analysis. The repository includes local and Docker setup instructions, plus optional SMTP delivery.
